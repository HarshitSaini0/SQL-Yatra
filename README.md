# 📊 SQL Yatra

Welcome! This repository contains the complete curriculum, code examples, and hands-on exercises from a 6-week SQL course I developed and taught. 

Originally built to help students transition from traditional spreadsheet logic to relational database querying, I am open-sourcing this material here so anyone can learn, practice, and master the fundamentals of SQL.

## 📂 What's Inside
- **Weekly Lesson Plans:** Structured 90-minute session guides.
- **Live Code Examples:** Ready-to-run SQL scripts (compatible with SQLite/DB Fiddle).
- **Hands-on Challenges:** Real-world business scenarios and homework assignments.
- **Cheat Sheets:** Quick reference guides for weekly syntax.
